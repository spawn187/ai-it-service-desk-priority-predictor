# Security incident first-response triage

## Scope and keywords
Security incident, phishing, malware, suspicious sign-in, data exposure, Defender alert, compromised account, biztonsági incidens, adatszivárgás.

## Safe diagnostic steps
- Preserve the original alert, ticket, timestamps, identifiers, and relevant logs without altering evidence.
- Confirm the potentially affected identities, devices, services, data types, and business processes.
- Review approved security telemetry and correlate the event with sign-in, endpoint, email, and audit logs.
- Notify the designated security incident owner through the documented escalation channel.
- Document every analyst action, decision, and evidence source in the incident record.

## Escalation criteria
Immediate security escalation is required for privileged identities, active compromise, suspected data loss, malware propagation, or broad user impact.

## Prohibited autonomous actions
Do not delete evidence, contact an attacker, reset privileged credentials, isolate assets, or revoke sessions without the incident owner's approval and a recorded rationale.
