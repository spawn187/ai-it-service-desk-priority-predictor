# Teams and SharePoint Online service triage

## Scope and keywords
Microsoft Teams, SharePoint Online, OneDrive, collaboration, meeting, file access, sync, jogosultság, fájlmegosztás.

## Safe diagnostic steps
- Confirm the affected workload, site or team, user population, UTC start time, and exact client error.
- Check Microsoft 365 service health and reproduce with the web client where appropriate.
- Review sharing, membership, sync, and audit information using approved read-only access.
- Compare one affected and one unaffected user to isolate identity, device, network, or content scope.
- Capture relevant URLs, correlation IDs, client versions, and recent configuration changes.

## Escalation criteria
Escalate tenant-wide collaboration outage, suspected oversharing, lost access to critical content, or audit evidence of unauthorized activity.

## Prohibited autonomous actions
Do not change permissions, ownership, retention, sharing policy, or delete content without explicit approval and an audit trail.
