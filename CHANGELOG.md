# Changelog

## 1.0.0 - 2026-08-18

- Added reproducible 30,000-ticket synthetic dataset generator.
- Added data-quality validation and duplicate removal.
- Added TF-IDF, categorical, and numerical preprocessing pipeline.
- Added logistic regression, linear SVM, and SGD benchmark training.
- Added business-oriented cross-validation and P1-focused weighting.
- Added persisted model, metadata, metrics, and evaluation figures.
- Added FastAPI service and Streamlit demonstration.
- Added local coefficient-based feature contributions.
- Added Docker, Docker Compose, tests, and GitHub Actions.
- Added optional MLflow tracking.
- Added architecture, model card, data dictionary, technical report, roadmap, and interview guide.
