# Changelog

## 2.0.0 - 2026-08-28

- Reframed the repository as a hybrid AI/ML Service Desk Copilot portfolio.
- Added a provider-neutral copilot orchestration layer above the classical priority model.
- Added local TF-IDF retrieval over version-controlled IT operations runbooks.
- Added PII, secret, and credential-pattern redaction before retrieval and prompting.
- Added direct and indirect prompt-injection signal detection.
- Added strict instruction/data separation and a versioned JSON response contract.
- Added prompt and input SHA-256 hashes for auditability and change control.
- Added deterministic offline advice for reproducible demos without API keys.
- Added a structured-generation adapter with schema validation and citation filtering.
- Added application-level policy re-enforcement after model/provider output.
- Added ten prompt/RAG regression cases and a CI release gate.
- Added a FastAPI copilot endpoint and a Streamlit copilot demonstration page.
- Added architecture diagrams, case study, prompt design, LLMOps, threat model,
  business case, ADRs, demo script, Hungarian interview defense, and application assets.

## 1.0.0 - 2026-08-18

- Added reproducible 30,000-ticket synthetic dataset generator.
- Added data-quality validation and duplicate removal.
- Added TF-IDF, categorical, and numerical preprocessing pipeline.
- Added logistic regression, linear SVM, and SGD benchmark training.
- Added business-oriented cross-validation and P1-focused weighting.
- Added persisted model, metadata, metrics, and evaluation figures.
- Added FastAPI service and Streamlit demonstration.
- Added local coefficient-based feature contributions.
- Added Docker, Docker Compose, tests, and GitHub Actions.
- Added optional MLflow tracking.
- Added architecture, model card, data dictionary, technical report, roadmap,
  and interview guide.
