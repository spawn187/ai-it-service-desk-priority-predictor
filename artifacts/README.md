# Experiment Artifacts

This directory contains the reproducible evaluation outputs for model version 1.0.0:

- `metrics.json`: selected holdout metrics and confusion matrix;
- `model_comparison.csv`: candidate model results;
- `data_quality_report.json`: duplicate and missing-value summary;
- `experiment_run.json`: local experiment record used when MLflow is not configured;
- `test_predictions_sample.csv`: small prediction audit sample.
