## CV project entry – English

**AI-Powered IT Service Desk Copilot | Independent Portfolio Project | 2026**

- Designed an end-to-end hybrid AI/ML decision-support architecture for IT service-desk triage, combining an explainable P1-P4 NLP classifier with retrieval-grounded first-response guidance.
- Built a reproducible 30,000-ticket synthetic-data workflow, leakage-safe scikit-learn pipeline, candidate-model comparison, holdout evaluation, and local feature-contribution explanations.

- Implemented pre-prompt PII/secret redaction, direct and indirect prompt-injection detection, citation filtering, mandatory human-review gates, and application-enforced `automation_allowed=false`.
- Created a local RAG corpus for Microsoft 365, Entra ID, Exchange Online, Intune, Windows 365, Teams/SharePoint, network, and security scenarios.
- Added FastAPI and Streamlit interfaces, Docker packaging, unit/API tests, GitHub Actions, prompt/RAG regression evaluation, architecture decisions, threat model, model card, business case, and production rollout plan.

## Interview claim boundaries

### Strong and accurate

- “I implemented the complete reference solution and can walk through the code.”
- “The metrics are reproducible on the committed synthetic-data workflow.”
- “The prompt/RAG gate checks ten deterministic cases.”
- “The provider adapter is designed and tested, while the default demo remains offline.”
- “Application policy overrides unsafe provider fields.”
- “I designed the enterprise operating model and can explain what remains before production.”

### Avoid

- “Production-proven.”
- “Enterprise deployed.”
- “Autonomous incident resolution.”
- “Guaranteed hallucination prevention.”
- “Certified OWASP/NIST compliant.”
- “Real company dataset.”
- “Fine-tuned LLM,” unless that is added and genuinely evaluated later.

## Suggested portfolio sequence on a CV

1. Place the GitHub link in the header or Projects section.

3. Link the repository title, not a raw long URL when possible.

6. Keep the synthetic-data limitation in the interview narrative, not hidden.
