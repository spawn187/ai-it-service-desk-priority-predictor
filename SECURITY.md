# Security Policy

## Supported version

The latest `main` branch is the supported portfolio version.

## Reporting a vulnerability

Do not publish sensitive vulnerability details in a public issue. Contact the repository owner privately through the GitHub profile associated with this repository.

## Data policy

This repository must never contain real service desk exports, personal information, credentials, API keys, access tokens, internal hostnames, IP-address inventories, or confidential incident descriptions.

## Production warning

The included API is a portfolio implementation. Before production use, add authenticated access, authorization, rate limiting, payload limits, PII redaction, structured audit logging, secret management, dependency and image scanning, network controls, and an approved incident-response process.
